# たぺいの予定（calendar-widget）

今日からの1週間の予定（端末のカレンダーと Google タスク）を1行に並べる、自分用の Android ホーム画面ウィジェット。

## 入れ方・更新

- Releases の最新の APK（`calendar-widget-v2.0.<番号>.apk`）をスマホで開いて入れる。
- そのあとは、アプリを開いて「更新を確認」→「更新する」。新しい版は通知でも知らせる。
- main に変更が入るたびに GitHub Actions が APK を作って Releases に出す（版の番号は自動）。

## 通信

- Google タスクの読み取り（読み取りだけ）
- アプリの更新：GitHub の Releases
